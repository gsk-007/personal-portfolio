# Portfolio Development Rules

## Goal

Build a premium, recruiter-friendly personal portfolio for a Full Stack Engineer targeting backend-heavy product engineering roles.

The portfolio should feel modern, minimal, and polished without being flashy.

Primary audience:
- Recruiters
- Hiring Managers
- Senior Engineers

## Design Principles

- Simplicity over creativity
- Premium over trendy
- Readability first
- Fast loading
- Accessibility
- Mobile-first
- Every section must have a purpose

## Things to Avoid

- Skill bars
- Percentage proficiency
- Large icon clouds
- Floating animations everywhere
- Heavy parallax
- Typing animations
- Terminal UI
- VS Code clones
- Excessive gradients
- Glassmorphism everywhere
- Long paragraphs

## Animations

Use Framer Motion sparingly.

Allowed:
- Fade
- Slide
- Scale
- Stagger
- Shared layout transitions

Avoid:
- Continuous floating
- Scroll hijacking
- Spin animations
- Cursor followers

## Components

Every component should

- be reusable
- be responsive
- have dark/light support
- have proper spacing
- use semantic HTML

## Code Rules

- App Router
- TypeScript
- Tailwind
- Server Components by default
- Client Components only when necessary

Keep components small.

Avoid premature abstraction.

## Performance

Aim for

- Lighthouse 95+
- Optimized images
- Minimal JS
- Lazy loading where appropriate
